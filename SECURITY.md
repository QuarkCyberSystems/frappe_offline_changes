# Security policy

This app receives changes to the records of a Frappe site and keeps, for a time, the values a device sent. On a site that holds personal data those values are personal data: access to the queue follows the rules in the README, and a weakness in them is a vulnerability.

Please report a vulnerability privately, never in a public issue or pull request. Email the maintainers at **vivek@quarkcs.com** with what is affected, the steps to reproduce it and whether you have told anyone else.

Use synthetic data only in reports, tests, fixtures and screenshots.
